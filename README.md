# 지도 앱이 모르는 변수까지 읽는 길찾기

인천 → 서울(서강대학교) 장거리 통학 경로를 대상으로, 지도 앱이 알려주는 시간과 실제로 체감하는 시간 및 피로도의 차이를 데이터로 분석하는 데이터분석 과제입니다.

## 1. 문제의식 (주제를 정한 이유)

1. 매일 왕복 3시간씩 통학함
2. 오래 앉아 가려고 버스만 타고 가다가 후회함. 너무 오래 걸리고 돌아가며, 버스가 바로 오지 않음
3. 지하철 칸 표시(1-1 등)만으로는 어디서 타야 출구·환승 통로와 가까운지 모름
4. 출구가 지하·지상으로 나뉘어 헷갈려서 길을 잃은 적이 많음
5. 인천행 서울 1호선 완행이 예상보다 늦게 도착한 적이 많음. 7분 늦게 온다던 용산급행을 탈걸 후회한 적이 많음
6. 환승 동선이 길고 복잡함
7. 날씨(더운 날, 습한 날)에 따라 걷는 게 나은 날과 그렇지 않은 날이 있음
8. 같은 시간인데도 날마다 사람 수가 다름. 콘서트·야구 같은 행사 때문일까?
9. 오전 10시면 출근이 끝났을 시간인데 왜 사람이 많은지 궁금함
10. 버스 배차가 매일 다름. 수요일은 늦게 나가도 괜찮았는데 지각 확정인 날도 있음

## 2. 프로젝트 구상

| 단계 | 내용 |
|---|---|
| 01 데이터 (변수 수집) | 운행 정보(실시간 도착, 과거 지연), 역 구조(환승 거리, 계단, 출구), 날씨(기온, 습도, 강수), 행사·일정(공연, 경기) |
| 02 분석 (예측) | 체감 시간(지연 가능성 반영), 체감 피로도(도보·오르내림·날씨 점수화), 혼잡 원인(행사·시간대·지연 구분), 개인 선호(도착 보장, 앉아 가기, 덜 걷기) |
| 03 결과 화면 | 앱 시간 vs 체감 시간, 오늘의 추천 경로와 이유, 환승 위치(통로와 가까운 칸, 출구 안내) |

### 범위
- **대상**: "인천에서 서강대학교로 통학하는 학생". 본인 경로를 대표 사례로 삼음
- **넓게**: 인천→서울 통학 수요와 혼잡을 공공데이터 통계로 보여줌 (나만의 문제가 아님을 보여주기)
- **깊게**: 실제 경로에서 직접 수집하고 분석함
- 인천1호선은 잘 이용하지 않으므로 제외함

### 통학 경로와 비교할 대안
| 경로 | 하차역 | 특징 |
|---|---|---|
| 536번 버스 → 동암역 1호선 → 신도림 환승 → 2호선 | 신촌 | 주 경로. 신도림 환승이 혼잡함 |
| 1호선(용산급행) → 용산 환승 → 경의중앙선 | 서강대 | 학교와 가깝지만 경의중앙선 배차가 김 |
| 1호선 → 2호선 → 6호선 | 대흥 | 정문 쪽 접근성 |

### 행사 변수
- **과거 분석**: 지난 야구 시즌의 경기일과 역별·시간대별 승하차 인원을 비교함. 특히 고척스카이돔은 가까운 역이 1호선 구일역이라 통학 경로 위에 있음
- **현재 적용**: 겨울 콘서트(고척돔, KSPO DOME, 잠실실내체육관), 배구(장충), 농구(잠실학생), 신촌·홍대 행사

## 3. 데이터 출처

| 변수 | 출처 | 상태 |
|---|---|---|
| 지하철 실시간 도착 (1·2·6호선, 경의중앙선) | 서울 열린데이터광장, 실시간 지하철 인증키 | ✅ 발급 완료 |
| 역별·시간대별 승하차 인원 | 서울 열린데이터광장, 일반 인증키 (CSV 다운로드도 가능) | 신청 |
| 마을버스 도착 | 공공데이터포털, 인천광역시 버스도착정보 (마을버스 노선 포함 여부 확인 필요) | 예정 |
| 날씨 | 공공데이터포털, 기상청 단기예보 | 예정 |
| 공연 일정 | KOPIS 공연예술통합전산망 API | 예정 |
| 스포츠 일정 | KBO / KOVO / KBL 홈페이지 (API 없음, 직접 정리) | 예정 |

> ⚠️ **과거 지연 데이터는 API로 받을 수 없음.** 실시간 API는 현재 시점의 정보만 주므로, 통학 시간대에 주기적으로 호출해서 데이터를 직접 쌓아야 함.

## 4. 환경 설정

### API 키
프로젝트 폴더에 `.env` 파일을 만들고 키를 넣습니다. `.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다.
```
SEOUL_SUBWAY_REALTIME_KEY=실시간_지하철_키
SEOUL_OPENAPI_KEY=일반_인증키
DATA_GO_KR_KEY=공공데이터포털_일반인증키(Decoding)
```
- 실시간 키: `swopenapi.seoul.go.kr`
- 일반 키: `openapi.seoul.go.kr`
- 두 키는 서로 바꿔 쓸 수 없음

### 시범 호출 (PowerShell)
신도림, 신촌, 구일, 서강대 역의 실시간 도착 정보를 표로 출력합니다.
```
powershell -ExecutionPolicy Bypass -File .\test_realtime.ps1
```
노선 코드: `1001`=1호선, `1002`=2호선, `1006`=6호선, `1063`=경의중앙선

### Python
- Python 3.14 (Windows installer 64-bit), 설치 시 **Add python.exe to PATH** 체크
- 사용할 패키지: `requests`, `pandas`, `python-dotenv`

### 7일 실시간 수집 (2026-11-16 ~ 11-22)
`collect_config.json`에 수집 계획을 적고, `collector.py`가 1분마다 실행되면서 해당 시각에 맞는 작업만 호출합니다. 결과는 `data/<api>/<날짜>.jsonl.gz`(원본 필드 + 수집 시각)에 쌓이고, `data/`는 커밋하지 않습니다.
```
py collector.py --plan     # 하루 예상 호출 수 (평일 766 / 주말 355, 실시간 키 일일 한도 1,000회 기준)
py collector.py --test     # API마다 1번씩 호출해 키 확인
powershell -ExecutionPolicy Bypass -File .egister_task.ps1   # 작업 스케줄러 등록 (end_date까지)
```
| 시간대 | 대상 | 간격 |
|---|---|---|
| 평일 07–10, 17–20 | 1·2호선 열차 위치 / 대안 경의중앙선·6호선 / 동암·신도림·용산 도착 예측 | 3분 / 6분 / 6분 |
| 매일 10–17 | 통학 4개 노선 기준선 | 30분 |
| 매일 18:00–22:30 | 공연장 노선 2·3·5·9호선 (1·6호선은 20시부터) | 8분 (10분) |
| 주말 13–18 | 1·2·5·9호선 (낮 공연·경기) | 10분 |
| 평일 06:30–10, 17–20 | 인천 536번 버스 차량 위치 (→ 동암역) | 2분 (하루 197회) |

- 열차 위치 API의 `recptnDt`(역 도착·출발 시각)와 `trainNo`로 같은 열차의 실제 구간 소요 시간을 다시 만들고, 도착 예측 API의 `barvlDt`와 비교해 '표시 vs 실제' 차이를 계산함
- 버스 위치 API는 차량 번호(`plainNo`/`vehId`)를 주지만 **기사 정보는 주지 않음**. 차량별 구간 소요 시간 편차를 기사 편차의 대리 지표로 쓰고, 이 한계를 보고서에 밝힘
- PC가 꺼지거나 절전 상태면 수집이 멈춤. 수집 기간에는 절전 모드를 '안 함'으로 바꿔 둘 것
